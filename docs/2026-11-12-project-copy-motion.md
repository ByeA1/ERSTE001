# 项目简介的字轮切换

参考效果为终端现有的 Rolling Text（字轮式滚动文字切换），由
`@kitlangton/rolling-number` 提供，不是打字机或随机字符解码。

档案盒内切换项目时，项目名称、副标题和概述摘要沿用相同引擎与
460 ms、direct、无逐字延迟、轻微运动模糊的参数。字符支持与现有终端一致：
字轮字符滚动，其他字符交叉淡化。

`src/project-copy-motion.ts` 测量原生段落的实际换行，每行建立临时字轮。
正文始终保留原生排版和唯一可访问/可复制的文字，装饰层标为 aria-hidden；
动画完成后恢复简单文本节点。先等待共享字轮完成旧值测量，再切换目标值，
避免同帧初始化被合并成直接替换。

动画使用终端已有帧入口，在档案盒和正文遮罩完成后开始。
首次显示不额外播放；重复值不播放。离开详情、切换标签、快速替换、窗口尺寸
变化及关闭文字动效时清理临时控制器。系统减少动态效果时直接显示完整正文。
不新增三维渲染循环、不更改项目演出或简介内容。

验证：构建、21 项站点回归测试、共享 Logo 使用检查；Edge 桌面 1440×900、
手机视口 390×750 的中英文切换、真实字轮动画、长文换行、快速项目切换、
窗口变化与减少动态效果检查。手机验证为浏览器模拟，并非 iPhone 真机。
浏览器检查与截图在本地 `.audit/project-copy-rolling/`，脚本为
`.audit/check-project-copy-rolling.mjs`。

既有 `audit-logo-unification.mjs` 仍因档案盒 GLB 哈希不匹配失败；本轮未修改该模型。
