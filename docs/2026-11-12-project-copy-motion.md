# 项目简介的字轮切换

当前实现：2026-11-13。

参考效果为终端现有的 Rolling Text（字轮式滚动文字切换），由
`@kitlangton/rolling-number` 提供，不是打字机或随机字符解码。

档案盒内切换项目时，项目名称、副标题和概述摘要沿用相同引擎与
460 ms、direct、无逐字延迟、轻微运动模糊的参数。字符支持与现有终端一致：
字轮字符滚动，其他字符交叉淡化。

`src/project-copy-motion.ts` 测量原生段落的实际换行，每行建立字轮。
正文始终保留原生排版和唯一可访问/可复制的文字，装饰层标为 aria-hidden；
动画停稳后保留同一字轮组件，与档案海的档案集名称一致。先等待共享字轮完成旧值测量，再切换目标值，
避免同帧初始化被合并成直接替换。

取消结束交接：字轮与原生段落的字偶距、两端对齐有差异，先前固定时间拆除和
后来的 200 ms 淡化交接都会在末段换到另一套可见排版。淡化只能隐藏瞬时切换，
仍会让观众看见第二次字距变化。当前结束时不替换节点、不切换文字渲染层，
让原字轮自然停稳；仅在字段被替换、离开详情、尺寸变化或关闭动效时释放。
研究/概述标签切换只释放该标签内容，保留项目标题和副标题的显示组件。

动画使用终端已有帧入口，在档案盒和正文遮罩完成后开始。
首次显示不额外播放；重复值不播放。离开详情、切换标签内容、快速替换、窗口尺寸
变化及关闭文字动效时清理相关控制器。系统减少动态效果时直接显示完整正文。
不新增三维渲染循环、不更改项目演出或简介内容。

验证：构建、21 项站点回归测试、共享 Logo 使用检查；Edge 桌面 1440×900、
手机视口 390×750 的中英文切换、真实字轮动画、长文换行、快速项目切换、
窗口变化与减少动态效果检查。手机验证为浏览器模拟，并非 iPhone 真机。
当前检查为 `.audit/check-project-copy-persistent.mjs`。从实际项目页发起切换，
逐帧确认可见字轮组件没有被替换、没有原生文字交接，比较停稳后的实际可见
字形位置，同时检查标签切换、连续切换、减少动态效果、窗口变化和退出释放。
记录及截图位于 `.audit/project-copy-persistent/`。
旧 `.audit/check-copy-handoff.mjs` 仅测量原生备用文字的边界，不能证明观众看到的
字轮字距不变化，已被当前的可见字形与组件身份检查取代。

既有 `audit-logo-unification.mjs` 仍因档案盒 GLB 哈希不匹配失败；本轮未修改该模型。
