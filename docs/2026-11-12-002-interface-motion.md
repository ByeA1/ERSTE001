# ERSTE002 界面与模型标注动效复核

2026-11-12。本次完善现有四章 11 镜的界面衔接，不改剧本、相机、灯光、模型或材质。

## 实际修改

- 模型标注按定位点、引线、文字的顺序入场。两项标注间隔 75 ms；文字在引线展开后进入。高度差虚线保留原来的虚线样式，并在 700 ms 内展开。
- 第 02、03、04、08 镜的所有现有模型标签复用同一套动效。退出采用 180 ms 淡出，保留最后的屏幕投影；快速切换最多保留一份退出副本，完成后移除，不复制 DOM ID。
- 常规镜头播放继续使用原有时间轴文案动效。章节直达、语言切换和自由查看返回时，为没有时间轴入场过程的文字补上短距离淡入，避免直接显现。
- 修正首镜将自身误作退出文案的问题，避免入场过程被压至不可见后在末尾突然出现。向上一镜倒放时，补充新文案的淡入，避免因倒放进度已越过入场段而直接显示全部文字。
- 项目工具、底部控制和右侧章节目录在项目可见后分批进入。底部镜头编号、章节名称、末镜重播按钮及自由查看的辅助操作增加短过渡。
- 自由查看面板与文案支持淡入淡出。退出中的面板立即停止接收操作；快速反向切换从当前透明度继续。
- 载入状态淡出后隐藏。失败信息使用轻量入场。仍保留原有就绪、重试和失败恢复机制。
- 尊重系统和宿主的减少动态效果设置。宿主暂停时，新增动画也暂停；页面销毁时取消动画并清理退出副本。

## 文件

- `public/cases/erste002/story-interface-motion.js` 为本次新增的 DOM 动效生命周期管理。
- `public/cases/erste002/story-interface-motion.css` 为标注分步展开及界面入场样式。

新增动效不使用独立的 requestAnimationFrame 循环，不延长三维渲染循环。没有修改统一顶部悬浮导航。
