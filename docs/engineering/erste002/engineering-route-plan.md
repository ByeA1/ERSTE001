# 后续 ENGINEERING 路线内容规划

本文件仅准备内容与证据结构，不开发网页。PRODUCT 保留现有四章 11 镜，ENGINEERING 是独立工程档案，不再制作第二套电影演出。

## 内容入口

以 REV00–REV03 的版本索引为主线，每版先展示可核实状态，再列设计目标、变更、实际测试、问题和后续行动。没有模型、照片或数据的位置明确留空，不用网站渲染填补物证。

## 可复用的数据

- `revisions.json` 提供版本基础索引，引用本档案中的记忆条目、问题编号与模型证据。
- 文件身份使用完整 SHA-256 加原始位置。未来页面使用另行审阅的轻量派生资源，不能直接引用 `_archive` 原件。
- 分开记录模型几何与实际打印件。一个 CAD 版本可以对应多个样件或测试批次，不把打印批次与 CAD 修订合并为一个不可追溯标签。
- 每个结论带来源类型、证据引用、核验状态和限制。工程假设与已确认结果必须在视觉和数据层区分。
- 版本关联、问题状态及结论更正保留历史记录，不删除失败迭代。

## 有证据后可建设的交互

1. 版本切换与同机位并排比较，明确对齐、单位和缩放方式；未确认坐标关系时不做貌似精确的叠加。
2. 从问题表定位局部，查看侧壁、筋位、横向构件、安装区和键盖，旁边显示原始证据及对应版本。
3. 有杆/无杆的装配对照，只在对应真实样件或可靠装配数据到位后开放。
4. 实际打印照片、装配视频、测试条件与原始记录入口，不把示意渲染标成试验照片。
5. 保留未通过、CAD 修改完成、等待验证和信息不足等状态，并可阅读每条问题的演进链。

## 当前可发布与应暂缓的内容

现阶段可作为资料草稿使用的是设计者已提供的阶段历史，以及明确标为候选包的文件目录与只读几何观察。

正式 REV 的模型切换需等待文件归属核对；装配干涉是否消除、刚度是否满足目标及重量是否达标需等待对应实物证据。H-001 只能作为待检验假设展示。

本阶段不新增路线入口、不动顶部导航、不改变终端或 ERSTE001，也不将候选历史模型加入生产构建。
