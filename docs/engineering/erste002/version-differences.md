# 版本差异与核对状态

## 正式 REV 演进 — 目前只由设计者记录支持

| 演进 | 已有支持 | 可写入的设计变化 | 尚不能确认的内容 |
| --- | --- | --- | --- |
| REV00 → REV01 | E-MEM-001，MC00-01～03、MC01-01～03 | 从 FDM 外形与握持验证推进到上盖、按键盖等分件，增加加强筋并进行首次 MJF 验证 | 两版对应文件、具体曲面改动、筋位尺寸、分件边界和打印日期 |
| REV01 → REV02 | MC01-04～05、MC02-01～02 | 在前轮整体刚度不足后引入支撑杆尝试改善刚度，并调整装配，再次 MJF 打印 | 支撑杆几何、数量、材质、位置，以及具体装配调整项目；不得写成刚度已改善 |
| REV02 → REV03 | MC02-03～10、MC03-01～02 | 针对上一轮结构与装配问题进行设计修改，等待实体打印 | 单项修改与问题的一一对应、最终硬件配合、刚度及电池固定实物结果；不能称已解决 |

## 候选包几何差异 — 尚未与 REV 建立对应

依据 E-GEO-001、E-VIS-001。以下是对收件内容的观察，不是正式版本关系结论。

| 对象 | 可观察差异 | 复核依据与限制 |
| --- | --- | --- |
| P01 / P02 | P01 没有单独的按键盖成员；P02 增加一个按键盖文件。上盖几何和网格内容并不相同 | ZIP 目录、M001/M002/M003 哈希及统一上视图。不能认定这是首次分件；P01 也可能只是提交不全 |
| P02 / P03 | 上盖前下部开口轮廓与横向构件布局发生可见变化；P03 的内侧有更明显的跨接构件 | `packages-upper/inside/transverse.png` 及 M002/M004 原件。构件的正式名称、材料与作用未核，不能直接称其为 MC02-01 的支撑杆 |
| P03 / P04 | 后部筋板可见轮廓与局部连接几何不同；按键盖内侧的连接与凸台轮廓不同 | `packages-ribs.png`、M005/M007 的 buttons 视图。只确认几何存在差异，不确认各项干涉已消除 |
| 前部安装区 | 同机位可对照前部凸台、筋板及开口，尚未收到与历史样件对应的真实 PCB、开关或侧键小板模型 | `packages-mounting.png`；不能凭没有电子件的视图判断与 PCB、支撑杆或微动之间的间隙 |
| 各 STL 三角形数变化 | 网格数量不同，哈希不同，包围盒也有少量差异 | 可能同时受导出细分影响。没有逐面 CAD 变更图，因此不把三角形增长当作新增筋数、材料量或减重证据 |

## 提升为正式版本差异的条件

1. 设计者确认某个原始文件/哈希对应哪次设计和打印批次，或提供可信导出记录。
2. 给出变更前后实际对应文件，明确坐标系、单位和零件命名。
3. 通过原始 CAD 或可靠网格对比确认位置和几何变化，保持来源链接。
4. 涉及实物结果时，另附对应批次的照片、装配记录或试验记录；几何证据不能替代实物结论。

目前未对候选包进行正式 REV 归属，也没有据此构造设计者未提供的中间版本。
