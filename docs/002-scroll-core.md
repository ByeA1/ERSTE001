## 预览与编辑

从项目目录启动 `npm run dev -- --port 5197`。

- 正常演出：`http://127.0.0.1:5197/cases/erste002/index.html`
- 自动展开编辑器：`http://127.0.0.1:5197/cases/erste002/index.html?editor=1`
- 终端入口不变，在 ERSTE002 档案中点击进入项目；保持同源 iframe、加载过渡及返回流程。

编辑器入口仅在 localhost / 127.0.0.1 / IPv6 loopback 出现。远程站点不显示开发面板。页面维持亮色、无声音，不增加主题或声音设置。

操作顺序：

1. 用进度滑块、精确进度或关键帧列表选取位置。
2. 调整镜头位置、观察目标、FOV；可先进入「自由查看」拖动取景，再保存当前镜头。
3. 调整主光、轮廓光、聚焦光的 XYZ 位置、XYZ 目标、强度、颜色和角度。灯光方向由位置与目标计算。
4. 调整切面位置、XYZ 角度、启用状态、切割目标和封口；辅助线只供调试，不会进入导出的演出数据。
5. 调整装配展开量、聚焦部件及提示闪烁起止进度/强度。可用「聚光灯对准所选部件」生成实际打光机位。
6. 点击「保存关键帧」写入内存轨道。同一位置覆盖原帧，其他位置新增，首尾 0/1 端点保留。字段调整先预览，保存后才成为轨道的一部分。
7. 「保存本机草稿」写入当前浏览器 localStorage，重新打开后需主动读取；正式演出不会自动读取开发草稿。
8. 「导出 JSON」下载 `erste002-story.json`。可再导入验证；要作为正式轨道，替换 `public/cases/erste002/story.json` 后重新构建。浏览器导出不会直接修改服务器文件。

文字轨道在面板中独立编辑 JSON，提供起止进度及中英标题/正文。文字随进度渐入渐出，使用 textContent 渲染。开发面板以中文显示；面向访客的文字与自由查看控件支持中英，和总站双向同步。

所有向量均为归一化场景坐标（模型最长轴约 0.30），不是 CAD 毫米。模型原坐标经过统一缩放居中；装配偏移叠加在每个部件原始位置上。FOV 与切面 Euler XYZ / 聚光角度以度存储。Plane 法向从 +Z 经 XYZ 角度旋转，负半空间被裁去。切面位置是平面上的一点。

每次渲染只采样当前 0–1 进度，不用章节触发器累积位移，因此反向采样得到相同状态。机位、灯光、切面与装配用逐段 smoothstep 插值；开关与目标部件是离散值。滚动只作一个与帧率无关的阻尼。文字与短暂自发光直接由同一进度计算；没有额外时间轴或自动播放。

## 模型检查与剖切

实际资源为 `assets/shell-hi.glb`，327,156 字节，总计 **94,707 三角面**。没有单独命名的加强筋网格；现场剖切可见上盖内部加强筋，因此先整体裁切上盖/装配。未伪造独立加强筋对象，也没有修改原 GLB。

解码后按位置 1e-4 原单位焊接统计：

| 节点 | 三角面 | 开口边 | 非流形边 |
| --- | ---: | ---: | ---: |
| bottom_plate | 2,548 | 0 | 0 |
| button_cover | 25,991 | 49 | 11 |
| shell_top | 66,168 | 599 | 3 |

检查脚本：`node scripts/inspect-002-model.mjs`。边统计是渲染网格的诊断，不是 CAD 实体质量认证。

采用 Three.js `Material.clippingPlanes` / `renderer.localClippingEnabled`；每个网格独立统计前后面 stencil，绘制受真实灯光影响的同色截面，并在部件之间清空 stencil。剖切无需拆开外壳与加强筋，也不会删除几何。支持全装配或单个部件裁切、平面移动旋转、切后继续运镜与打光、关闭裁剪及逆向复原。

**封口限制**：这是视觉封口，未产生可导出的 CAD 封闭实体。源上盖/按键盖存在开口和非流形边，某些位置、角度或镜头进入后可能漏封或出现杂面。面板可关闭封口继续查看真实内壁。要把封口做到任意切面都可靠，下一步应修复 CAD 导出网格，优先获得封闭且法向一致的部件；不能靠改透明度或染色掩盖。

实现参考：[Three.js r183 clipping stencil 官方示例](https://github.com/mrdoob/three.js/blob/r183/examples/webgl_clipping_stencil.html)。

## 灯光与提示约束

- 保留源模型材质颜色、粗糙度与不透明度；模型不靠变色或透明淡出来突出部件。
- 主光、轮廓光、聚焦光都是真实 SpotLight，方向由位置/目标确定。演示聚焦时降低主光、轮廓光和环境光，使用聚焦灯照亮切开的结构。
- 默认提示区间 16%–24%，18%/22% 为两个脉冲峰，24% 及之后自发光颜色和强度归零；之后才推进聚焦镜头与灯光。
- 提示是进度函数，反向滚动同样可回放。减少动态效果设置下关闭提示闪烁、取消滚动阻尼。
- 编辑器允许自由组合参数，正式分镜仍需校准光位与提示先后；它不会自动判断 CAD 部件或强制修正用户创作的轨道。
