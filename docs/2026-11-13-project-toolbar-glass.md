# 项目页半透明毛玻璃工具栏

## 已实现

- 公共工具栏使用 64% 不透明度的浅色/深色填充，局部 `backdrop-filter: blur(14px) saturate(110%)`，保留 Safari 前缀。下拉作品菜单同样使用半透明毛玻璃。
- 001 沿用浅色与中性操作色，002 沿用深色和红色强调。返回终端始终可见。
- 移除宿主顶部整条预留背景区域，项目 iframe 铺满视口；工具栏外两侧直接显示项目页面并接收项目交互。
- 公共服务测量工具栏实际高度，通过 `--project-toolbar-inset` 让文档内容和固定演出根节点避让。尺寸变化时更新，隐藏及销毁后的项目不继续处理。没有新增持续动画循环。
- 001 保留原封面构图及上一轮的章节居中规则，图片查看器留出工具栏安全距离。002 的相机、灯光、演出数据和正文没有更改。

## 实际检查

- Windows Edge 构建预览：001 六种视口、八章、中英文共 96 个落点，居中、长章起点、反向跳转、章节高亮及无溢出通过。
- 桌面、390px 和 320px 手机视口：002 全部 11 镜、重播、初始总装、中英切换、两个项目返回通过。
- 桌面与手机：两侧命中元素均为项目 iframe，顶部不再有独立的背景挡板。
- 工具栏计算样式：001 为 `rgba(255,255,255,.64)`，002 为 `rgba(20,20,23,.64)`；均为 14px 毛玻璃。
- 注入红/蓝背景进行实际像素验证：工具栏同一像素随背后项目背景由 `(247,176,176)` 变为 `(177,177,249)`，确认不是仅设置透明属性但背后仍有不透明挡板。
- 图片关闭按钮不受工具栏遮挡；缓存项目切换及窗口尺寸变化后的避让高度同步通过，无页面异常。
- 仅通过注册表在浏览器接入临时测试项目，公共工具栏和内容避让正常，无项目 ID 分支。测试未写入正式注册表。
