# 档案指令 · 终端茶色与项目主题按钮

采用已预览的「档案指令」方案；网站修改在开发分支，不部署。

## 层级

- 档案海「查看项目展示」、档案盒「进入项目」：烟茶色玻璃、暖白文字、对角角标。
- 档案盒「返回项目集」：深烟茶色玻璃。
- 项目切换与检视：浅茶色半透明底、细线框，保留原有尺寸和位置。
- 所有项目共享的「返回终端」：保持现有导航结构，按浅色/深色主题适配玻璃按钮。
- ERSTE002「下一镜 / 回到开头」：恢复黑红主题的红色半透明主操作；上一镜和初始总装使用中性浅色玻璃，初始总装边线为红色。
- 详情页桌面右下签名移至左下，避开进入项目按钮；手机原有隐藏规则保留。

## 半透明与反馈

实际计算样式：档案海入口 alpha 0.73；档案盒详情的进入项目 0.66、返回项目集 0.61、
悬停进入项目 0.73、项目选择和检视 0.08。002 下一镜 0.90、002 返回终端 0.09。
全部按钮局部使用 `blur(6px) saturate(105%)`，含 Safari 前缀。
没有对页面、三维画布或文字模块整体模糊。没有通过整个按钮 opacity 降低文字对比。

悬停轻微放大与箭头移动，按下轻微下移；终端确认使用短暂内框。
尊重减少动态效果设置；禁用按钮使用低强调半透明底，行为和可访问属性不变。
