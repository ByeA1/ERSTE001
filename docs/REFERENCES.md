# 参考与方向（法厄同大人指定）

## 002 项目页：围绕模型的镜头讲解

**指定参考**（2026-11-05）：https://tsogjavklann.github.io/awwwards-3d/templates/room-walkthrough.html

拆解到的做法：
- 滚动驱动、章节化。每一章有编号 + 标题（`01 — THRESHOLD`、`02 — SWEEP`…），左上角常驻，不抢画面。
- 画面里只有一句大白话文案压在大字位置，随滚动替换，不堆段落。
- 场景是连续的三维空间，镜头在章节间推进/横移/推近，章节切换靠镜头的运动完成，而不是切页面。
- 配色大胆但克制：整章一个主色（砖红、黑、浅蓝块），文字用暖白。
- 没有导航按钮、没有进度条，靠滚轮自然推进；信息密度极低，一屏一句话。

映射到 002：
1. 五章：全景 → 光心 → 开关槽 → 按键盖抬升 → 三件展开；左上角编号 + 英文小标题。
2. 每章一句中文，压在留白处；技术参数（Ø11、1.6mm、5N）只在该章出现一次。
3. 镜头用缓入缓出在机位之间过渡，章节切换时对应部件高亮、其余降透明度。
4. 保持我们现有的米白底 + 红色点缀，不照搬它的砖红。
